# Zhanna Kinzhalinova — сайт-визитка

Одностраничная визитка в стиле [dennissnellenberg.com](https://dennissnellenberg.com). Сделана сначала под телефон.
Чистые HTML/CSS/JS, без сборки и внешних зависимостей: шрифт Inter Tight лежит в самом репозитории.

## Структура

```
index.html                 — разметка
css/style.css              — стили (mobile-first)
js/main.js                 — анимации и интерактив
assets/photo-*.avif|webp   — фото для первого экрана (640/960/1200px)
assets/photo.jpg           — то же фото в JPEG для старых браузеров
assets/avatar.webp|jpg     — аватарка для футера
assets/fonts/              — Inter Tight 400 (латиница, кириллица), лицензия OFL
assets/favicon.svg         — иконка вкладки
zhanna-kinzhalinova.vcf    — визитка для кнопки «Save contact»
llms.txt                   — краткая карточка для ИИ-агентов
```

## Фото

- Портрет на первом экране отдаётся в AVIF/WebP трёх размеров (640, 960, 1200px), браузер сам выбирает подходящий. `assets/photo.jpg` — запасной вариант.
- При замене фото нужно пересоздать все `photo-*` файлы и `avatar.*` (200×200).
- Если фото не загрузится, на его месте появится силуэт-заглушка.

## Анимации

- Лоадер с приветствиями на разных языках; шторка уходит вверх со скруглённым краем. При повторном открытии в той же вкладке лоадер пропускается.
- Огромное имя бежит строкой, направление и скорость зависят от скролла.
- Магнитные кнопки и заливка, которая поднимается снизу (на телефоне срабатывает по нажатию).
- Строки контактов появляются при скролле.
- На десктопе за курсором над контактами ездит синий кружок с подписью («Write», «Call», …).
- Плавающая круглая кнопка меню и выезжающая панель с изогнутым краем.
- В футере белый изгиб распрямляется при скролле, стрелка поворачивается.
- Если в системе включено «Уменьшить движение», анимации отключаются.

## Запуск локально

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Публикация на GitHub Pages

Settings → Pages → Source: *Deploy from a branch*, указать ветку и папку `/ (root)`.

## QR-код

Папка `qr/` (ведёт на https://knzhanna.picta.cc):

- `qr-light.svg` / `qr-light.png` — тёмные точки на белом, синие «глазки», фото в центре. SVG — для печати в любом размере.
- `qr-dark.svg` / `qr-dark.png` — белые точки на тёмном фоне.
- `qr-card.png` — готовая карточка 1080×1350 для сторис и соцсетей.

Пересоздать с другой ссылкой: `pip install segno pillow && python qr/make_qr.py https://новая-ссылка`.
